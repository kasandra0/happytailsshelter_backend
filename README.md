## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone <your-repo-url>
cd happytailsshelter_frontend
```

### 2️⃣ Install dependencies

```bash
npm install
```
### 3️⃣ Run the development server
```bash
npm run dev
```
Navigate to Local:   http://localhost:3000/
